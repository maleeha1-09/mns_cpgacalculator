# MNS CGPA Calculator 🎓

A Flutter-based mobile application developed to help university students calculate their Cumulative Grade Point Average (CGPA) quickly and accurately. Built as a final project by **Group 8**, MNS University of Agriculture, Multan.

## 📱 About

Manually tracking CGPA across semesters can be tedious and error-prone. This app provides a simple, mobile-first tool for students to enter their course grades and credit hours and instantly get their semester and cumulative GPA — no spreadsheets required.

## ✨ Features

- Add courses with credit hours and obtained grades
- Automatic GPA calculation per semester
- Cumulative CGPA calculation across multiple semesters
- Clean, student-friendly mobile interface
- Cross-platform support (Android & iOS)

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed
- Android Studio / VS Code with Flutter & Dart plugins
- An emulator or physical device for testing

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/maleeha1-09/mns_cpgacalculator.git
   cd mns_cpgacalculator
   ```
2. Install dependencies
   ```bash
   flutter pub get
   ```
3. Run the app
   ```bash
   flutter run
   ```
